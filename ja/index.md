22nd Theorem Proving and Provers Meeting
{: .lead }

<!-- 定理証明系・証明支援系に関する研究会
{: .tagline } -->

TPP は2005年から毎年開催される、定理証明器や証明支援系のユーザと開発者がアイデアを交換する場です。 定理証明技術に関心のある方々が広く集まる場を目指しています。

## 開催情報

<ul class="event-list">
  <li><strong>開催日程：</strong>2026年11月16日（月）から17日（火）まで</li>
  <li><strong>会場：</strong>理化学研究所 革新知能統合研究センター（理研AIP）東京オフィス</li>
  <li><strong>住所：</strong>〒103-0027 東京都中央区日本橋1-4-1 日本橋一丁目三井ビルディング15階（<a href="https://www.riken.jp/access/tokyo-map/">アクセス情報</a>）</li>
  <li><strong>共催：</strong>理化学研究所 革新知能統合研究センター（理研AIP）</li>
  <li><strong>幹事：</strong>園田翔（理研AIP / CyberAgent）、谷口雅弥（理研AIP）</li>
  <li><strong>連絡先：</strong><a href="mailto:sho.sonoda@riken.jp">sho.sonoda@riken.jp</a></li>
</ul>
